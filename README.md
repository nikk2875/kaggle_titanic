# kaggle_titanic
This project is my personal attempt to build a prediction model on the infamous Kaggle Titanic competition. My primary goal was to better understand ML concepts, you will find much more successful models out there. At the beginning, I used more traditional techiques (Random Forrest and XGBoost), but I also plan to build a model with a shallow Neural Network (with Tensorflow).

You can find my work in a Jupyter notebook. There are sections describing my actions.
